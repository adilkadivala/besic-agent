**Goal:** Understand “if I nudge w, does the result go up or down?”

## Q&A

### Q1 — What does slope tell you?
**Student answer:**
slope defines how result will change when something changes; positive: input rises → output rises; negative: input rises → output falls; helps training reduce errors

**Teacher feedback:** 9.5/10 — excellent intuition. Spelling: negative, reduce.

### Q2 — Training direction: if error slope is positive, move w which way?
**Student answer:**
I'll do always opposite with w to reduce error

**Teacher feedback:** 10/10 — correct rule (move opposite error slope). For positive slope that means decrease w.
