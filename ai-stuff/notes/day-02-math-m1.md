## Q&A

### Q1 — What is a variable?
**Student answer:**
variable is a name which holding some value ex. x = 25 , so now x is a variable which holds 25

**Teacher feedback:** 10/10 — perfect. Name + holds a value + example.

### Q2 — Compute y = 2 * x + 1
**Student answer:**
y = 21

**Teacher feedback:** 10/10 — correct. Steps: 2*10+1 = 20+1 = 21

### Q3 — Compute y = w * x + b with given numbers
**Student answer:**
y = 14

**Teacher feedback:** 10/10 — 3*4+2 = 12+2 = 14

### Q4 — If w gets larger (x and b fixed), what happens to y?
**Student answer:**
then y will get a big output

**Teacher feedback:** 10/10 — yes; for positive x, larger w → larger y. (If x were negative, larger w would make y smaller — advanced note for later.)

## M1 complete ✓
All 4 questions correct. Student can: define variable, plug into y=w*x+b, reason about weight.
